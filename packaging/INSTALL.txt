LIGHT SEEKER - Light-fantasy location effect (macOS, Apple Silicon and Intel, macOS 10.15+)

INSTALL
  1. Quit GarageBand and Logic.
  2. Open Terminal (Applications > Utilities > Terminal).
  3. Type "bash " (with a space), drag install-mac.sh from this folder into the
     Terminal window, and press Return.
  4. Wait for "LIGHT SEEKER is installed and validated."

  Why a script? This build is not signed with an Apple Developer ID. When a browser
  downloads it, macOS marks every file as quarantined and then refuses to load the
  plug-in: GarageBand shows a silent slot with plain sliders. The script removes that
  flag, re-signs the plug-in for this Mac, refreshes the Audio Unit list and runs
  Apple's validator.

GARAGEBAND
  Settings > Audio/MIDI: tick "Audio Units". Restart GarageBand.
  Select a track (software instrument or audio). Smart Controls (B) > Plug-ins >
  an empty Audio Effect slot > Audio Units > Veil Audio > LIGHT SEEKER.
  Play the track: the plug-in window opens on the painted map. Click a landmark to
  travel there; inside, click the rings or the list to visit its places.
  If you see sliders instead of the LIGHT SEEKER interface, switch the plug-in
  window's view menu from "Controls" to "Editor".

MIDI TRAVEL
  GarageBand does not send MIDI to audio effects: use Journey or Roam (Journey
  button) or automate Location / Sub-location instead. See README for other hosts.

LOGIC PRO
  Settings > Plug-in Manager > Veil Audio > LIGHT SEEKER. If it is marked failed,
  select it and click "Reset & Rescan Selection". Insert it in an Audio FX slot of
  any track: Audio Units > Veil Audio > LIGHT SEEKER.

SIDE BY SIDE WITH DUNGEON CRAWLER
  Both can be installed at once: LIGHT SEEKER is aufx Lsek Veil (LightSeeker.component,
  audio.veil.lightseeker); DUNGEON CRAWLER is aufx Dgcr Veil. The scripts of one never
  touch the other's files.

UNINSTALL
  bash uninstall-mac.sh            (add --purge to also delete your presets and
                                    drop-in scenes in ~/Library/Application Support/LightSeeker)

MANUAL INSTALL (if you prefer not to run the script)
  cp -R LightSeeker.component ~/Library/Audio/Plug-Ins/Components/
  xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/LightSeeker.component
  codesign --force --deep --sign - ~/Library/Audio/Plug-Ins/Components/LightSeeker.component
  killall -9 AudioComponentRegistrar
  auval -v aufx Lsek Veil
