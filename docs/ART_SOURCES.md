# LIGHT SEEKER: art sources

All art is original and generated in this repository; no image of anyone else's is used.
The developer's mood references (romantic, luminous fantasy paintings) informed the palette
and light only; they are not copied or committed.

| Art | Source |
|---|---|
| Painted map and scenes | scripted Blender scenes (`tools/painted/scenes.py`: 32 scenes, original geometry, daylight), rendered with Cycles as depth layers and painted by a post-process (`tools/painted/paint.py`); shipped in every bundle (`Contents/Resources/Painted`) |
| Fallback scenes | drawn in code (`Source/UI/Scenes.cpp`): a luminous wash per place, shown when a scene's painted files are missing |
| Icon | `tools/icon/make_icon.py` |
| Fonts | Cinzel, Cormorant Garamond (SIL Open Font License, `assets/fonts`) |
| Leaf and blossom sprigs (the trees' leaf cards, Direction Update 2) | drawn in numpy by `tools/painted/detail.py` (`_sprig_image`) at build time into `build-art/textures/` (not committed): original |
| Every material (bark, stone, cliff, marble, gold, golden boughs, leaves, grass, petals, water, glass, cloud) | Blender shader nodes built in `tools/painted` (procedural noise, Voronoi, waves): no image textures |

## External assets and textures

**None.** Direction Update 2 allowed CC0 assets and textures (with their source and licence
logged here); the re-rendered art did not need any: every tree, leaf, rock, material and
texture is generated by the scripts in `tools/painted`. Nothing was downloaded, and nothing
is taken from the developer's reference images (they informed the palette and light only).
If a CC0 asset is ever added, log it in this table:

|---|---|---|---|
| (none) | | | |

## Drop-in art

Your own or commissioned art replaces any scene:
`~/Library/Application Support/LightSeeker/scenes/<location>/<place>.png` (and `map.png`),
for example `scenes/celestial-citadel/gates-of-dawn.png`; or a folder of layers (`back`,
`far`, `mid`, `fog`, `near`) for parallax.
