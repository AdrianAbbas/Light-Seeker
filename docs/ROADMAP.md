# LIGHT SEEKER roadmap

**1.0.0 is frozen** (2026-11-12, tag `v1.0.0`). The 1.0 line takes bug fixes only (1.0.1,
1.0.2, …): something that is broken, crashes, fails validation or loses a user's work. Nothing
that changes the sound, the look or the controls goes into 1.0.x.

Every new idea, request or "it would be nice if" goes to the list below, one line each, with
where it came from. Nothing on it is promised; it is where 1.1 starts.

## 1.1 ideas

Seeded from the "Known issues and decisions to revisit" sections of
[DEVLOG.md](DEVLOG.md); add new ones at the end.

- The Diamond Vault's own glints still carry a fixed-pitch shimmer in a chord's tail; a
  drier option without losing the vault (celesta's softer ring).
- More sparkle for the celesta through its tine and air, not the vault's share (same).
- A Developer ID signed and notarised download, so no install script is needed (the CI path
  exists but has never run with real credentials).
- A way to travel by MIDI in GarageBand, which sends no MIDI to audio effects (today:
  Journey, Roam or automation).
